# 🟡 PAC-MAN — C# 콘솔 게임

> 교육용 콘솔 게임 프레임워크(`Engine`) 위에 **팩맨을 처음부터 직접 구현한** 프로젝트입니다.
> 원작의 유령 4마리 AI, 파워 펠렛 / 프라이튼드 모드, 콤보 점수 체계를 재현했습니다.

| 항목 | 내용 |
|------|------|
| 언어 / 플랫폼 | C# 9.0 · .NET 10.0 · Windows 콘솔 |
| 화면 | 60 × 40 문자 버퍼, 약 30 FPS |
| 맵 | 28 × 31 타일, 펠렛 244개 |
| 외부 라이브러리 | 없음 (BCL + Win32 API만 사용) |

---

## 🎮 실행 방법

```bash
git clone https://github.com/Devel-Rocket-ClassRoom/0-console-game-project-jinag8904.git
cd 0-console-game-project-jinag8904
dotnet run
```

> ⚠️ 입력 처리에 `user32.dll`의 `GetAsyncKeyState`를, 색 출력에 Windows 콘솔의 ANSI 모드를 사용하므로 **Windows 환경에서 실행해야 합니다.**
> 맵이 전각 문자로 그려지므로 콘솔 창은 **가로 60칸 / 세로 40줄 이상**으로 열어 주세요.

### 조작

| 키 | 동작 |
|----|------|
| ↑ ↓ ← → | 팩맨 이동 |
| `Enter` | 게임 시작 / 재시작 |
| `Esc` | 종료 |

* 미로의 **펠렛 244개를 모두 먹으면 클리어**, 유령에게 닿으면 즉시 게임 오버입니다. (목숨 1개)

* 남은 펠렛이 20개 이하가 되면 **빨간 유령이 점점 빨라집니다.**

### 점수

| 대상 | 점수 |
|------|------|
| 펠렛 | 10 |
| 파워 펠렛 | 50 |
| 유령 (한 번의 파워 펠렛 동안 연속으로) | 200 → 400 → 800 → 1600 |

유령을 잡으면 게임이 2초간 멈추고 잡은 자리에 획득 점수가 표시됩니다.
최고 점수(HIGH SCORE)는 프로그램이 실행되는 동안 유지되어 화면 상단에 계속 표시됩니다.

## 👻 유령 AI

원작의 네 유령이 가진 서로 다른 추격 성격을 각각의 클래스로 구현했습니다.
모든 유령은 공통적으로 **BFS로 네 방향의 목적지까지 거리를 계산해, 가장 가까워지는 방향**을 매 이동마다 선택합니다. 즉 성격의 차이는 "목적지를 어디로 잡는가"로 표현됩니다.

| 유령 | 목표 지점 | 등장 |
|------|-----------|------|
| 🔴 **Red** (Blinky) | 팩맨의 현재 위치를 그대로 추격 | 즉시 |
| 🟣 **Pink** (Pinky) | 팩맨이 보고 있는 방향으로 **4칸 앞**을 매복 | 즉시 |
| 🩵 **Mint** (Inky) | 팩맨 2칸 앞을 기준점으로, **빨간 유령 → 기준점 벡터를 2배로 늘린 지점** | 5초 후 |
| 🟠 **Orange** (Clyde) | 팩맨과 8칸 이상 떨어지면 추격, 가까워지면 좌하단 구석으로 도주 | 15초 후 |

프라이튼드 상태에서는 목적지를 벽이 아닌 임의의 타일로 잡고, 도착하면 다시 새 목적지를 뽑아 예측 불가능하게 배회합니다. 잡힌 뒤에는 목적지를 자기 집으로 바꿔 최단 경로로 복귀합니다.

## 💡 구현하면서 신경 쓴 점

**BFS 기반 경로 탐색**
유령이 인접한 네 칸 각각에서 목표 지점까지의 실제 미로 거리를 BFS로 구하고 그중 최솟값을 고릅니다. 직선거리로 판단하면 벽에 갇혀 제자리를 맴돌지만, 이 방식은 막다른 길을 피해 돌아갑니다. 터널 좌우 순환도 탐색에 포함했습니다.

**비트 플래그 타일 맵**
한 칸에 벽 · 펠렛 · 팩맨 · 유령 4종이 동시에 존재할 수 있어, 타일을 `[Flags]` enum으로 정의하고 비트 연산으로 겹침을 관리했습니다. 충돌 판정은 팩맨이 선 칸의 유령 비트를 한 번 검사하는 것으로 끝나며, 여러 유령에게 동시에 닿는 상황도 자연스럽게 처리됩니다.

**깜빡임 없는 렌더링**
매 프레임 화면 전체를 문자·전경색·배경색 버퍼에 그린 뒤 ANSI 이스케이프로 한 번에 출력합니다. 색이 바뀌는 지점에서만 색상 코드를 삽입해 출력량을 줄였습니다. (`ScreenBuffer` — 제공된 엔진)

**이벤트로 분리한 모드 전환**
`GameScene`이 파워 펠렛 섭취를 감지해 `OnFrightenedMode` / `OffFrightenedMode` 이벤트를 발생시키고, 유령 4마리가 각자 구독해 상태를 바꿉니다. 씬이 유령 목록을 순회하며 직접 상태를 건드리지 않도록 했습니다.

**입력 반응성**
`Console.ReadKey`는 키 반복 지연 때문에 방향 전환이 늦어져, `GetAsyncKeyState`로 매 프레임 키 상태를 폴링하고 직전 프레임과 비교해 "눌린 순간"을 구분하도록 했습니다. 또한 팩맨은 벽 쪽으로 입력이 들어와도 방향을 예약해 두었다가 통로가 열리면 즉시 꺾습니다.

**속도 연출**
펠렛을 먹는 순간에는 이동 간격을 0.12초 → 0.14초로 늘려 원작의 "먹으면서 살짝 느려지는" 감각을 재현했고, 유령은 상태별로 이동 속도가 다릅니다 (평소 0.13초 / 도망 0.25초 / 귀환 0.05초).
